What is Docker?

Docker is a platform that packages an application together with everything it needs to run — code, runtime, system libraries, and settings — into a single unit called a container. Because the container includes its own environment, it runs the same way on any machine that has Docker installed, whether that's a developer's laptop, a testing server, or a production cloud instance. This solves the classic "it works on my machine" problem and makes applications easy to build, ship, and deploy consistently.

This website itself is a small demonstration of that idea: instead of hosting these three HTML pages directly, they are copied into an Nginx web server image and served from inside a Docker container.
