Docker Concepts Learned in This Course

  • Image: A read-only template that contains an application's code, dependencies, and configuration. Images are built from a Dockerfile and are used to create containers.
  • Container: A running instance of an image. It is an isolated, lightweight process that includes everything the application needs, and multiple containers can run from the same image at once.
  • Dockerfile: A text file containing step-by-step instructions (such as FROM, COPY, and EXPOSE) that Docker follows to automatically build an image.
  • Port Mapping: A way of connecting a port on the host machine to a port inside the container (for example -p 8080:80), so services running inside the container can be accessed from outside it.
  • Docker Hub / Base Images: A public registry of pre-built images, such as nginx:alpine, that developers can use as a starting point instead of building an environment from scratch.
  • Volumes and Bind Mounts: Mechanisms for persisting or sharing data between the host machine and a container, so data isn't lost when a container stops or is removed.
